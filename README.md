# Kinal App

Es un sistema desarrollado con Spring 
Boot que permite gestionar clientes, productos, 
usuarios y ventas dentro de una aplicación. 
Facilita el registro de transacciones y el 
control de detalles de venta mediante una 
API conectada a una base de datos MySQL.

## Tecnologías Utilizadas
* **Java 21**
* **SpringBoot 4.0.2**
* **Maven** (Gestor de dependencias)
* **MySQL** (Sistema Gestor de Base de datos)

# Requisitos Previos 
Antes del proyecto debe de tener:
* JDK 17 en adelante
* Maven instalado
* Una instancia activa en MySQL

## Como se intala y se ejecuta
Se debe de entrar al cmd por comando entrar 
a la carpeta donde usted desea clonarlo
entra y descarga las ramas para poder entrar
a la dev o achacon-2025216 y poder usar la app
